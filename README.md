# Live Location - Fase 2

## Ejecutar
1. Descomprime el ZIP.
2. Abre la carpeta en CMD o VS Code.
3. `npm install`
4. `npm run dev`

Esta versión crea sesiones temporales, permite entrar por código/enlace y sincroniza participantes mediante Supabase Realtime.

Nota: las políticas RLS actuales son para MVP/pruebas. Antes de producción se debe implementar autenticación/token por participante y políticas más restrictivas.
